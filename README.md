# Instant Volume Reducer

Press **F7** during gameplay to instantly toggle a temporary master-volume reduction. Satisfactory's native text notification displays **Instant Volume Reducer: On** or **Instant Volume Reducer: Off**. The game controls the notification's appearance and lifetime. Every loaded session starts with the reducer disabled.

Requires SML **3.12.1** and Satisfactory build **520140 or newer**, compatible with that SML version.

- Default reduction: **50%**.
- Configure **5–95%** in **Mods > Instant Volume Reducer** (main menu or pause menu).
- Rebind **Toggle volume reducer** under **Options > Controls > Instant Volume Reducer**.
- Changes to reduction intensity apply immediately while enabled.
- The normal master-volume preference is preserved. Disabling the reducer or leaving the session restores normal volume.
- Only your local audio is affected; other players' audio and your savegame are unchanged.
